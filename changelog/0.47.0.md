### Highlights

- **The Tagger page is gone and some view shortcuts have moved.** Tag search now lives in a sidebar on the Search page. Ctrl+3 now opens Decks, Ctrl+4 to Ctrl+8 each move up one, and Ctrl+9 opens Settings again.
- **You can split a deck row onto another printing.** In the deck editor you can move some copies of a card to a different printing and leave the rest of the row where it was.
- **You can share deck groups, Recently removed folders and wishlists.** Every kind of collection folder can now be shared, and your wishlist can be shared as well.

### New

- **Decks:** right-click a deck card and choose Split to new printing to move some of its copies to another printing in one step that undo can reverse (#947)
- **Decks:** the deck editor's card search remembers the width you dragged it to, separately for each deck (#942)
- **Decks:** Ctrl+A in the deck editor widens your selection to every card in each stack that already has a picked card, and does nothing when nothing is picked (#948)
- **Search:** unreleased cards now appear in the default search, stamped with their set code and release date (#950)
- **Search:** tag search is a sidebar on the Search page that you can collapse or resize, and it remembers whether it was open and how wide it was (#951)
- **Sharing:** you can share a named deck group, the Recently removed folder, or your wishlist and its folders (#953)
- **General:** an open trade has a Swap sides button between the two sides that moves every card to the other side in one press (#946)
- **Android:** on a phone, the search page has a Tags button beside Filters that opens tag search (#951)

### Changed

- **Search:** the Tagger page is removed and its tag search now lives in the sidebar on the Search page (#951)
- **General:** the page title is gone from the top of each page, Refresh data is an icon button in the window header, and the mana progress bar sits directly under the header (#949)
- **Web:** the web app shows the same header band as the desktop app, and F1 opens the keyboard map (#949)
- **General:** Ctrl+3 now opens Decks, Ctrl+4 to Ctrl+8 each move up one row, and Ctrl+9 opens Settings again (#951)
- **General:** copies past what your collection holds for a printing go on a separate trade line, and the collection mark shows how many copies you own (#952)

### Fixed

- **Decks:** the Foil and Etched filters in the deck editor's search now add that finish when you press Add or drag a card, and the results show the sheen (#943)
- **Collection:** Select all no longer picks cards in a closed folder that you open after pressing Ctrl+A (#948)
