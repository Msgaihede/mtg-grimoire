### Highlights

- **The app now opens on a home page you can arrange yourself.** Home has six widgets for deck and folder shortcuts, price totals, a totals row and a feed of recent actions, and you choose the opening view in Settings.
- **Ctrl+9 no longer opens Settings.** Home is now the first shortcut, so the number keys move down one place and Settings has no shortcut; you can still reach it from the side bar.
- **The old deck notes box is gone.** The single notes box in deck settings has been replaced by many notes per deck, and the text in the old box is not carried over.
- **Both pie charts have been removed from deck stats.** The deck stats now show their figures as bars and readouts, and the curve by colour readout shows mana value.

### New

- **General:** a new home page with six widgets you arrange yourself, showing shortcuts to decks and folders, price totals for your collection and wishlist, a row of totals and a feed of recent actions grouped by day, with the layout saved on each device (#459)
- **Settings:** under appearance there is now an opening view setting that chooses which screen the app opens on (#459)
- **Decks:** a notes section in the deck editor holds as many notes as you like for a deck, each with a title and formatted text, and each note can name any number of cards (#457)
- **Decks:** right-clicking a deck card now offers add note to create a note already naming that card, and notes to bring up the notes that name it (#457, #458)
- **Decks:** a deck card with notes shows a note mark beside its game changer crown (#457)
- **Decks:** a card's own window lists every note written about it, across all of your decks (#457)
- **Decks:** every change to a deck's notes can be undone like other deck edits (#457)

### Changed

- **General:** the shortcut ctrl+9 no longer opens Settings, because home is now the first screen and the number shortcuts move down one place (#459)
- **Decks:** the single notes box in deck settings is gone, and any text it held is not carried over to the new notes (#457)
- **Decks:** the deck stats are now a section you can open or close, shown as seven readouts in two columns, and it remembers whether it is open for each deck (#449)
- **Decks:** the mana pips readout counts the mana symbols printed on each card's cost (#449)
- **Decks:** the mana symbols in the cost and sources bands of deck stats are now plain coloured symbols without a round background (#456)
- **Decks:** the game changers count in the deck ledger is a button again, which filters the deck to its game changers and turns gold while that filter is on (#454)

### Fixed

- **Decks:** the mana pips colour tiles use a larger text size that is readable, instead of the app's smallest size (#452)
- **Decks:** the label picker on a deck card shows the picked colour's swatch on the closed box as well as in the open list, and a long label name ends with an ellipsis instead of wrapping out of the box (#453)
- **Decks:** the red edge of a rule-breaking deck card is no longer cut off at its top corners by the quantity tag or the plan tick, and the bottom corners no longer show a sliver of background (#455)
