### Highlights

- **Decks can hold several titled to-do lists.** Each deck's to-do list is now one titled list, and you can add more lists, with plain text lines as well as to-dos.
- **Update every device before editing to-dos.** To-do edits made on a device with the previous version do not reach devices with this version, so update all of your devices.

### New

- **Decks:** you can keep several titled to-do lists in one deck, with plain text lines as well as to-dos (#689)

### Changed

- **Decks:** to-do lists appear as note-style cards showing their title, where you can tick items, edit or delete the list (#689)
- **Decks:** the deck's home widget shows each to-do list under its own title, after the deck's name (#689)
- **Sync:** to-do lists do not sync between a device on this version and one on the previous version until both are updated (#689)
- **Decks:** the Notes and To-do sections sit side by side when the deck editor is wide enough, and stack one above the other when it is narrow (#697)
- **Decks:** the quantity buttons on the tokens tile are larger, the same size as the buttons in the deck list (#690)

### Fixed

- **Decks:** arrow keys now step onto tokens in the card and printings views instead of doing nothing (#692)
- **Decks:** cards added from search, tags, the wishlist, the collection or by dropping onto the Decks entry now go to the deck's chosen add location instead of being sorted automatically (#698)
- **Decks:** notes and to-do lists show less than, greater than and ampersand as typed instead of as codes such as &gt; (#696)
- **Decks:** a note or to-do line beginning with a dash, plus sign, hash or number and full stop is no longer turned into a list or heading and lost when reopened (#689)
- **General:** the sidebar no longer shows menu labels while it is collapsed (#695)
