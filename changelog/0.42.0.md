### Highlights

- **You can now create a deck straight from scanned cards.** The scanner review tray has a Create deck action that opens the deck settings, then fills the new deck with the scanned cards. Scans stay in the tray for adding to your collection separately.

### New

- **Scanner:** the scanner review tray has a Create deck action that makes a new deck from the scanned cards, using the format, cover and settings you choose (#839)
- **Collection:** you can export a collection folder and its subfolders from the folder's options menu (#832)

### Fixed

- **Decks:** the New folder button in the deck gallery works when the folder sidebar is hidden or collapsed (#833)
- **Scanner:** resetting the scanner clears the previous card straight away and stops it from reappearing afterwards (#837)
- **Scanner:** cards without an Oracle ID no longer add an extra row to the tray when you switch between Fast and Exact or change filters while the same card is in view (#838)
