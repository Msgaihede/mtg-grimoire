### Highlights

- **Decks now count only the copies you have filed to them.** Each deck has a locked group in your collection folders, and a copy counts as owned by a deck only when it sits there. The automatic allocation is gone, and a card you cut from a deck goes to Recently removed.
- **The setting that let your collection follow your decks is gone.** The Settings row for that mode has been removed, so the collection now shows only the copies you entered yourself.
- **The deck header lost its game and format selects.** Deck game and deck format can no longer be changed from the header. The format is still shown there, and both are set in Deck settings.

### New

- **Collection:** you can file copies into nested folders of your own, drag cards between them, and see on each row where that copy is filed (#217)
- **Decks:** each deck gets a locked group in your collection that holds its copies, and copies cut from a deck wait in Recently removed to be sorted back, while a deck card you do not own simply does not add anything to your collection (#219)
- **Decks:** the deck builder's search column has a Collection Search tab that lists the copies you own and where each is filed, with an option to show copies other decks are holding, and the ordinary card search has an own or need switch that defaults to need (#220)
- **Decks:** importing a deck can file its copies into that deck's group, so the list and the group agree straight away (#220)
- **General:** Escape now closes the open deck or steps up one folder in decks, the collection and the wishlist, so pressing it again eventually returns you to the start (#224)
- **General:** you can select several cards with Ctrl or Shift click and drag the whole selection together, and the card menus act on the selection; undoing a multi-card move takes one press of Ctrl+Z per card (#226)
- **Import & export:** importing an Archidekt deck brings in the coloured labels on its cards, and you choose which labels to bring in (#227)
- **Import & export:** exported decks can include their labels, in Archidekt files and as a Tag column and a Tag colour column in CSV files, and the CSV import reads those columns back (#231)
- **Search:** there is a Rarity filter with four chips for common, uncommon, rare and mythic (#229)
- **Search:** there is a Price filter that limits results to a price band in your marketplace, where cards with no price are left out once either end of the band is set (#229)

### Changed

- **Settings:** the deck-driven collection row is removed from Settings (#216)
- **Decks:** Add to then Collection is no longer greyed out in the deck menu (#216)
- **Import & export:** the import dialog no longer refuses to import when a deck-driven collection setting is involved (#216)
- **Collection:** setting a copy's quantity to zero now deletes that row, along with its condition, price, date, source, notes and tags, and adding a copy onto a row already holding that printing merges the two and names the destination (#217)
- **Decks:** cutting a card from a deck is recorded in the deck's history but cannot be undone with the Undo button, which names the change it would reverse (#219)
- **Decks:** the deck editor's header is now three lines, with the action buttons on top, the deck's totals beneath them, and the tools below, and the totals appear only once (#228)
- **Decks:** the variant switch reads Live, Compare, Theory from left to right (#230)
- **Decks:** the collection tab in the deck panel shows your copies as a grid of cards with the same filters as the card search, and the Collection and All cards choice is a tab bar (#222)
- **Decks:** the deck editor scrolls as part of the page rather than inside its own box, so there is one scrollbar
- **Search:** the first sort option, which used to be called Default order, is now called Best match (#225)
- **Search:** the filter row is now a bar with the search box, colours, mana values and sort, while the other filters sit behind a Filters button and the active ones show as chips, and Owned is two buttons (#229)
- **General:** the sidebar reads Search, Tagger, Decks, Collection, Wishlist, Settings, Tags is now called Tagger, and Decks and Collection have their own icons (#221)

### Fixed

- **Collection:** a Scryfall printing update could move a copy into a row in a different folder, and now it cannot (#217)
- **Import & export:** re-importing a collection now updates a row you have altered or graded instead of adding a second copy beside it (#217)
- **Decks:** adding a copy to a deck or taking it from another deck now records the change in that deck's history, and adding an owned copy shows the card landing like other adds (#220)
- **Search:** the price bar only fills in gold once a price band is set, so it no longer looks like an active filter when untouched (#232)
