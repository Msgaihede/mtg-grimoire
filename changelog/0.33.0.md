### Highlights

- **The Tokens choice for managed wishlists has changed.** Tokens is no longer one of the modes. Decks that used it now use Missing with a separate Tokens switch turned on, and the switch works with every card view.
- **Deck completion no longer measures a plan against every copy.** Under the Collection comparison a deck is measured by its live list, so the old plan figure is gone. Theory mode compares the actual list with the theory list instead.
- **The deck editor filter box understands search terms.** Type terms such as t:instant or c:red and they combine with the words you type.
- **Stacks can be hidden in the Stacks view.** A hidden stack keeps its heading and count but draws no cards, and an eye button shows it again. Hidden stacks stay on the device where you hid them.

### New

- **Decks:** you can hide a stack in the Stacks view from its right-click menu, and a hidden stack keeps its heading and count but draws none of its cards (#630)
- **Decks:** the filter box in the deck editor now understands the same search terms as the card search, such as type, text, keyword, colour, mana value and tags, and combines them with the words you type (#629)
- **Decks:** the mana curve can split each bar into creatures and other cards, with a legend, and the choice is saved for each deck (#625)
- **Decks:** the card distribution panel now shows creatures against other cards, a list of creature types, and a land breakdown by basic land type (#625)
- **Decks:** a deck that keeps a plan gets an Add to actual or Add to theory row in a card's right-click menu, which adds one copy to the other list and creates a matching pile there if it is missing (#639)
- **Sync:** hidden stacks are kept on the device where you hid them and do not sync to your other devices (#630)
- **Collection:** you can remove or move many collection entries at once, and removing more than one asks you to confirm first (#640)
- **Collection:** an import into the collection or the wishlist, and a bulk remove or move, can be undone from a notice that appears afterwards, unless those cards have changed since (#640)
- **Import & export:** you can import a spreadsheet exported from other apps such as Deckbox, Moxfield, ManaBox, Dragon Shield, TCGplayer, MTGO, MTGGoldfish and Archidekt, with their column names recognised (#640)
- **Import & export:** a collection file's tags, tradelist counts and language are now imported, and the import preview lists any columns it could not read and warns when there is no quantity column (#640)
- **General:** the deck completion widget has a compare choice, Collection or Theory, and a choice of all decks or chosen ones that it can measure (#632)
- **General:** the wishlist savings widget counts wishes in deck-managed wishlists, with a switch to leave them out and a choice of which wishlists to count (#633)

### Changed

- **Decks:** the Tokens choice for a managed wishlist is now a separate switch that works with every card view, and a deck that used Tokens now uses Missing with the switch on (#634)
- **Decks:** pressing a token in the deck's token pile now opens its card details, and changing its art is a separate button on the card (#628)
- **Decks:** each token tile in the Tokens & Emblems band shows its controls across the full width, with its colour and stats below, and no longer repeats the token name (#635)
- **Decks:** the deck stats band lays out in three columns on wide windows, with its labels above the bars, and keeps two columns on narrower ones (#625)
- **Decks:** the coloured fills in deck stats and across the app now use only the mana colours, with gold as the accent colour (#625)
- **Decks:** a stack's count now sits beside its name, and its price alone on the right (#630)
- **Search:** the colour Exact toggle sits beside the colour chips on every search header as a round button whose icon shows AND or OR (#624)
- **Search:** the View all printings dialog has one row of filter controls with a Reset all button, and its count moves under the card name (#622)
- **Collection:** clicking a folder's name now folds or unfolds it, and a new arrow button opens the folder (#638)
- **Collection:** the Not sorted section stays on the collection and wishlist screens even when it is empty, so a card can always be dragged back out of a folder into it (#637)
- **Wishlist:** in the optimise dialog a wish in a deck's managed wishlist shows its saving but has no tick box, and must be changed from its deck (#633)
- **General:** the Folders widget with nothing pinned lists each cabinet's top-level folders, including deck groups and Recently removed, drawn in the collection's colour (#631)
- **General:** the deck completion figure that measured a plan against every copy it could be built from is no longer shown, and under the Collection comparison a deck is measured on its live list (#632)
- **General:** a long table or card grid now takes one Tab stop and the arrow keys move through its rows or cards (#636)
- **Import & export:** text in a spreadsheet export that starts with an equals sign, plus, minus or @ is kept safe, and it comes back unchanged when imported (#640)
- **Import & export:** the set these quantities import option no longer doubles copies you have filed in folders, and the preview says how many copies stay in folders (#640)
- **Import & export:** if an export cannot be read, the export dialog shows a message with a Retry button and its copy and save buttons stay off (#640)
- **Import & export:** pile names with commas or brackets are written in a form Archidekt reads back correctly (#640)
- **Import & export:** a file that is not UTF-8 text is read as Windows text rather than garbled, and the dialog says so (#640)

### Fixed

- **Wishlist:** tokens in a managed wishlist's Tokens folder no longer show a foil shine, and a nonfoil copy never does (#627)
- **General:** the Ctrl plus number shortcuts work on AZERTY keyboards (#636)
- **General:** buttons such as Add that grey out while you type stay in keyboard order instead of dropping out of reach (#636)
- **General:** groups of choices in dialogs such as export and price history can be moved through with the arrow keys (#636)
- **Import & export:** the import mode choice is read aloud by its label alone, with its explanation announced as a description (#641)
- **Import & export:** an Archidekt list with a pile name ending in brackets, such as Removal (cheap), now imports its cards into that pile, and cards under a Commander heading no longer stay in the command zone (#642)
- **Import & export:** a count written as 1.5 or 3 copies is flagged in the import preview instead of being read as 1 or 3 (#640)
