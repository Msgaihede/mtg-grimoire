### Highlights

- **Search now understands Scryfall's syntax and a: and o: mean something new.** Keyword filters such as `t:`, `kw:` and `cmc:` now work in every card search box. `a:` now means artist and `o:` means oracle text, so `o:ramp` no longer finds the ramp tag; use `otag:ramp` for that.
- **Colour matching can be made exact and cards can be filtered by type.** An Exactly option makes a colour search match only cards with exactly the colours picked, and eight card type chips narrow search, collection, wishlist and the deck editor.

### New

- **Search:** search boxes accept Scryfall's keyword filters such as `t:`, `o:`, `kw:`, `cmc:`, `pow:` and `r:`, with operators like `>=`, a leading `-` to leave a term out, and quoted phrases, and they work the same in search, the collection and the wishlist (#498)
- **Search:** an Exactly chip beside the colour choices makes a search match only cards whose colours are exactly the ones picked, so picking red and white no longer also brings up mono-red, mono-white and colourless cards (#496)
- **Search:** eight card type chips (creature, planeswalker, instant, sorcery, artifact, enchantment, battle and land) filter search, the collection, the wishlist and the deck editor, and a card with several types appears under each of them (#496)
- **Search:** the help panel has a Search syntax tab beside Shortcuts that lists every keyword the card search understands (#498)

### Changed

- **Search:** `a:` now searches artists and `o:` searches oracle text, as on Scryfall, where they used to search the art and oracle tags (#498)
- **Search:** tag searches keep their older names such as `otag:` and `arttag:`, so existing habits still work (#498)
- **Search:** searching by artist is much faster on the full card list (#498)
- **Search:** the stated colour filter reads for example Colour: exactly White, Blue when Exactly is on, and the number on each colour chip follows the same setting (#496)
- **Decks:** the deck editor has room below its last section, so the bottom section no longer sits flush against the edge of the window (#494)
- **Decks:** the counts in a deck's ledger and tallies are written in one style, with the same spacing around plus and minus signs, and the tokens and notes counts use the same figure style as the rest of the page (#494)

### Fixed

- **Search:** the Instant filter keeps Capital Offense, whose type line is printed in lower case, instead of dropping it after the next sync (#497)
- **Decks:** the owned and missing figures in a deck's ledger are spaced consistently, so one no longer crowds the word beside it (#494)
