### Highlights

- **Deck exports leave out switched-off piles by default.** Plain, Moxfield, Archidekt, TCGplayer and CSV exports no longer write a deck's switched-off piles unless you tick the Include inactive categories box in the export dialog. The dialog shows how many copies ticking it would add.
- **New copies no longer assume a grade.** A copy you add without choosing a condition is now marked Not set rather than Near Mint. Copies you already own keep the grade they have.
- **Artist credits no longer show on deck tiles.** The Art by line has left deck gallery tiles and folder cards. The artist's name now appears as a tooltip when you hover over the picture.

### New

- **Decks:** a colour bar under each deck's art shows the colours its cards ask for, and a Commander bracket appears in the caption, either your own answer or an estimate (#394)
- **Decks:** the deck gallery has a filter row with a name box, format chips, an Archived chip and a sort picker with six orders and a direction arrow, and the chosen sort is remembered (#394)
- **Decks:** a Tokens & emblems band below a deck's stats lists the tokens and emblems its cards make, and lets you pick the art for each and set how many to bring (#397)
- **Decks:** a button in deck settings opens the pull from collection dialog so you can bring in the cards the deck is missing (#396)
- **Decks:** a deck can turn off its green tick, so a card in the exact printing your plan names shows a blue tick instead (#398)
- **Collection:** the collection and the wishlist each have a card search panel on the right, which opens and closes and remembers whether you left it open (#399)
- **Collection:** each search result has a plus button that adds the card to the folder you are standing in, and you can drag results onto folders or breadcrumbs (#399)
- **Collection:** the add popup has a Purchase price field that starts blank and shows the current market price for that printing and finish as a hint you can overtype (#393)
- **Collection:** a copy's condition and price can be changed from its card menu, though a price once set can be changed but not cleared (#393)
- **Collection:** the collection can be filtered to copies with the condition Not set (#393)
- **Settings:** theory mark colours can be chosen under Appearance, with a reset to the defaults (#398)
- **Settings:** labels can be managed in Settings without opening a deck (#398)
- **Import & export:** the deck export dialog has an Include inactive categories box that decides whether switched-off piles are written (#391)

### Changed

- **Decks:** the Art by line is removed from deck gallery tiles and folder cards, and the artist's name shows as a tooltip on the picture (#394)
- **Decks:** copies of a printing a deck no longer lists are moved to Recently removed, where the pull from collection dialog offers them first (#396)
- **Collection:** new copies are recorded with the condition Not set instead of a grade, and existing copies keep theirs (#393)
- **Import & export:** deck exports no longer include a deck's switched-off piles unless Include inactive categories is ticked, which changes what an export contains by default (#391)
- **Import & export:** a copy with no condition exports an empty Condition cell, and an import line that gives no condition is recorded as Not set (#393)

### Fixed

- **Decks:** a deck could show cards as missing while the pull from collection dialog offered none, and the two now agree (#396)
- **Decks:** a card sleeved in different art than the plan names now shows a blue tick, where before it showed nothing (#398)
- **Decks:** a Commander deck's commander and companion now show the plan marks, which they did not before (#398)
- **Collection:** the card name column of the collection and wishlist tables no longer gets squeezed out when the search panel is open (#399)
