### Highlights

- **Hosted sync needs a Patreon membership.** Sync through the hosted service is for Patreon supporters, and if a membership lapses sync stops while the data on your devices stays put.
- **An account can pair five devices at most.** A sixth device is refused until one is removed or left, so check your device list before pairing a new one.
- **Custom deck covers are gone.** A deck's cover is now the art of one of its cards, so a picture you set yourself is no longer used.
- **Pairing needs both devices updated and online.** Pairing now passes through the sync service, so both devices need this version and a connection, and an older version cannot pair with it.
- **Removing a device now reaches every device.** The group's key changes when a device is removed and the others pick up the new key, so a removed device stops syncing everywhere.
