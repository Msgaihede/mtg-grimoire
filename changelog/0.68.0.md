### Highlights

- **Deck copies can no longer be changed from a card's window.** Copies sitting in a deck's folder can't be stepped, deleted, re-finished or re-printed from a card's window any more, so the deck's count stays right. Change those copies from the deck itself.
- **Locked folders stay out of deck pulls.** Copies in a locked collection folder are no longer offered by Pull from collection, so they aren't moved into a deck by accident. Unlock the folder to pull them again.
- **Sent scans now help train the card finder.** The scanner's card finder has been retrained on scans readers sent in, so it finds cards more reliably. Sending a scan now keeps a copy of its pictures on the maker's computer and in the cloud for training, and deleting the scan removes those copies too.

### New

- **Scanner:** you can zoom the scanner's card tray with Ctrl and the scroll wheel, on the page and in the pack opener, and the zoom is remembered (#1528)
- **General:** with the sandbox on in playtest, you can move cards in an opponent's graveyard and exile, just as in your own (#1529)
- **Decks:** a deck's card count in the gallery is drawn in red when the deck is not the size its format needs, with the reason on hover (#1530)
- **Decks:** in a deck's Collection tab, owned tokens and emblems can be added to the deck's Tokens and Emblems pile (#1605)
- **Android:** on the phone, Import and Export are offered on an empty collection, when a search finds nothing and when the folder you opened is gone (#1653)
- **General:** the notes widget on the home page shows its notes in pages when there are more than fit, and a note can be pinned from its editing window (#1635)

### Changed

- **General:** in playtest, your hand, life, cards and taps can be edited whenever the game is waiting for you, including during combat, and a step the game passes is editable once you set a stop there (#1567)
- **General:** starting a new draft while one is already at the table asks first, and Abandon no longer takes a draft that a hosted pod is still using (#1637)
- **Import & export:** when a file has no readable lines, the reason is shown under the file box on the first step instead of only a count (#1634)
- **Decks:** closing a deck note with unsaved words asks whether to discard them, and Escape keeps writing rather than throwing words away (#1623)
- **Collection:** Pull from collection no longer offers copies that sit in a locked folder, including folders inside it (#1639)
- **Collection:** when moving several copies, the choice of which copies names each card, so two cards with the same name or printing can be told apart (#1649)
- **Collection:** a copy that a deck holds can't be stepped, deleted, re-finished or re-printed from a card's window, and the window says why (#1655)
- **Scanner:** the scanner's card finder reads cards more reliably, sent scans are kept for training and the privacy notice says so (#1667)
