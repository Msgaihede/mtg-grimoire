### Highlights

- **Moving a card between piles now needs a drag.** The per-card move dropdown in the deck editor is gone, and there is no keyboard way to move a card yet.
- **Piles the app makes are hidden when empty.** A pile the app creates while filing a card appears only while it holds cards, and an emptied one is found and removed from the Categories panel.
- **The Unplayable chip is folded into the format list.** Its job is now the top rows of the format select, which offers Any card, Any format and each named format.
- **Right-click menus across the app.** Right-clicking a card, deck, folder or category opens a menu of what you can do with it, in search, collection, wishlist and the deck editor.
- **Deck editor sidebars are now pop-up windows.** Import, categories, tags, history and settings open as centred pop-ups from the toolbar, and the card search panel starts collapsed.

### New

- **Decks:** a new deck opens on the format you last created a deck in, or on Commander if you have not made one yet (#58)
- **Decks:** the card search in the deck editor opens on the deck's own format, and you can still switch it to any format (#57)
- **Decks:** you can drag the left edge of the card search panel to make it wider or narrower (#67)
- **Decks:** a card you have open is outlined, and a card you just added to a deck is marked for ten seconds (#72)
- **General:** right-click a card, deck, folder or category, or use the keyboard, to open a menu of actions for it (#74)
- **Search:** open all printings of a card from its right-click menu (#74)
- **Import & export:** export a deck from a dialog that offers several formats and saves the result to a file (#74)
- **Sharing:** copy a Scryfall or marketplace link for a card from its right-click menu (#74)

### Changed

- **Decks:** the per-card move dropdown is removed, so a card is moved between piles by dragging it (#53)
- **Decks:** empty headings in the deck editor depend on the format, so Commander appears only where the format has a command zone and Companion only with a companion, while piles you make always show (#56)
- **Decks:** the Maybeboard sits in the right-hand column under the Sideboard (#56)
- **Decks:** piles the app creates while filing cards show only while they hold a card, and the Categories panel lists them all (#61)
- **Decks:** deck history, categories and tags open as pop-up windows from the toolbar instead of side panels (#59)
- **Decks:** the card search panel in the deck editor starts collapsed (#59)
- **Decks:** the empty deck gallery says No decks in place of a paragraph about what a deck is (#58)
- **Decks:** the stacks view spreads piles across the width of the desk and wraps them downwards (#65)
- **Decks:** the deck builder grows with its content and the whole page scrolls, instead of a box inside it scrolling (#73)
- **Decks:** zooming the card search changes the card size at every step of the zoom (#67)
- **Decks:** the deck editor's header buttons and controls share one height (#69)
- **General:** each card area keeps its own zoom, and ctrl and scroll zooms only the area under the pointer (#63)
- **General:** the sidebar, ribbon and text are one size larger throughout the app (#62)
- **Search:** the Reset all button is always shown, greyed out when there is nothing to clear (#55)
- **Search:** the format select starts with Any card, which includes cards that are not playable in any format (#70)
- **Search:** a count on a search result card is a grey badge without a times sign (#71)
- **Sync:** the first-run screen shows the app name and the same progress line as the ribbon, and Retry appears only when it can help (#52)

### Fixed

- **Search:** the filter row no longer shifts sideways when you press a colour or mana chip (#55)
- **Sync:** pressing Retry clears the old error message from the first-run screen (#52)
- **Decks:** the deck editor no longer scrolls sideways, and a filter row in the search panel no longer overflows it (#65)
- **Decks:** a card with a rule break shows its red outline all the way round, including its bottom strip (#68)
- **Decks:** the focus ring on the deck name field is no longer cut off at the top (#69)
