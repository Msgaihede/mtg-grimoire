### Highlights

- **The scanner has a new Neural mode.** The scanner can now run in a third mode, Neural, which recognises most cards from the picture alone. It sits beside Fast and Exact as a trial, and on the web it downloads about 27 MB the first time it is used.
- **MTGO text exports put the commander in the sideboard.** A commander in an MTGO export now sits after SB: as a sideboard line, so importing the file back no longer counts it as a 100th main-deck card.

### New

- **Scanner:** a third scanner mode called Neural recognises a card from its picture alone, usually on the first frame, and asks which printing you have when several printings share one picture (#1224)

### Changed

- **Import & export:** an MTGO text export writes the commander after SB: so it comes back as a sideboard card rather than as an extra main-deck card (#1239)

### Fixed

- **Import & export:** a binder import that stopped part way resumes where it stopped when you press Import again, without adding the same cards or decks twice (#1240)
- **Import & export:** an Arena list with an About block but no Deck line now imports all its cards instead of dropping them (#1232)
- **Import & export:** importing an MTGO .dek deck file reads its cards correctly instead of turning each line of the XML into a card (#1244)
- **Import & export:** a deck CSV keeps its switched-off piles switched off when it is imported, and the deck CSV has a Category active column that records this (#1242)
- **Import & export:** an Archidekt export made without the Category column no longer writes a pile heading that comes back as a card (#1238)
- **Import & export:** a wishlist import that merges repeated wishes keeps the notes from every merged line and lists the merged lines in the preview (#1237)
- **Import & export:** the import preview shows the list you pressed Preview on, and the text box and file button are locked while that list is being read (#1243)
- **Wishlist:** pressing Add again after a partial add adds only the wishes that did not land the first time, instead of doubling the ones that did (#1240)
- **Sharing:** withdrawing a shared list removes its published copy even when the first attempt failed, so trying again works (#1226)
- **Settings:** clearing your decks or your collection refreshes the wishlist straight away, so it no longer shows deleted folders or old owned marks (#1235)
- **General:** Tab stays inside a dialog when a group of radio buttons is its last control (#1234)
