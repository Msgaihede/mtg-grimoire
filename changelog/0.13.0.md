### Highlights

- **A new Tags page and tag filters for your cards.** You can now browse and search Oracle Tags and Art Tags, and filter your cards by them, which makes it easier to find cards that do a particular thing or show a particular picture.
- **Card art is sharper on large and high-resolution screens.** Cards in walls and deck views are now drawn at a size that matches the screen, so the art no longer looks blurry; the image cache takes more space as a result.

### New

- **Search:** a new Tags page lets you search and browse Oracle Tags and Art Tags in a tree (#153)
- **Search:** you can filter cards by Oracle Tags and Art Tags, and the facet counts narrow to match (#153)
- **Search:** you can mute individual tags (#153)
- **Collection:** hovering over a language code on a printing shows the language's name, such as Phyrexian, and the language picker lists languages by name with their printing counts (#174)

### Changed

- **General:** card art is drawn at a larger size, so cards take about 93 KB each in the image cache instead of about 62 KB, and images cached at the old size are not cleared automatically (#155)

### Fixed

- **General:** blurry card art on screens with display scaling or zoomed-in card walls is now sharp (#155)
- **Decks:** the quantity-style mark on a card in a deck is now centred and sits flush with the card's edge, matching the quantity mark (#170)
- **Decks:** the Theory tab no longer shows the Live tab's marks on every row when you switch to it (#173)
- **Collection:** the View all printings panel is three quarters of the window wide rather than the full width, so a card with only a few printings no longer sits in an empty wide panel (#171)
