### Highlights

- **Your collection shows a reduced price.** Beside the value of your collection the app now shows what your cards would fetch after a sell percentage and a minimum card value that you set in Settings.
- **Playtest asks you to split combat damage.** When two creatures block one attacker you now choose how its damage is divided, instead of the game deciding which blocker dies.
- **Open Packs can price from several marketplaces.** You can pick several marketplaces for Open Packs and each card is valued at the lowest price among them, as long as they all use one currency.

### New

- **Prices:** you can pick several marketplaces for Open Packs and each card is valued at the lowest price among them, as long as they all use one currency (#1454)
- **Prices:** Open Packs has its own sell percentage and minimum card value, and the reduced price appears in brackets beside the total value of an opening and of a session (#1461)
- **Collection:** the value of your collection shows a reduced price in brackets beside the full value, based on a sell percentage and a minimum card value, and hovering it shows how it was reached (#1457)
- **Collection:** the total value graph draws a dashed line for the reduced price when it is shown in dollars (#1457)
- **Settings:** there is a Collection value entry where you set the sell percentage and minimum card value, with a live breakdown of your own collection and a reset button (#1457)
- **Android:** the Android app shows the reduced price of your collection, but it does not yet show how that price was reached (#1457)

### Changed

- **Search:** an unreleased printing shows a red calendar icon beside its set and collector number instead of a label on the card art, and hovering the icon shows its release date (#1459)
- **Scanner:** the Neural mode recognises cards printed up to November 2026, with nearly a thousand more card pictures than before (#1447)
- **General:** the Open Packs value histogram shows each band as a percentage of packs instead of a count, and the home page price histogram shows percentages of cards (#1452)
- **General:** sets are grouped under their release year, newest first, when you choose a set to open or put packs in order for a draft, and the set tiles no longer show the year (#1460)

### Fixed

- **Decks:** when two or more creatures block an attacker the game now asks you how to divide its combat damage, instead of the blocking order silently deciding which blocker dies (#1455)
