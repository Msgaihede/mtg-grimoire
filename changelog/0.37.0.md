### Highlights

- **Stacked cards are now picked up.** A card laid on one the scanner has already read used to be ignored until the first card was lifted; it is now recognised.
- **The scanner decides faster.** A clear match is now decided in about four camera frames instead of ten, and a locked card takes about half the processing per frame.
- **A few cards are read less reliably.** In our tests Super Shredder is no longer recognised, and in some small groups the right card is named with a different printing more often.

### Changed

- **Decks:** a token at zero on the Tokens & Emblems band now has a clearly dimmer picture, so it stands apart from the counted tokens beside it (#714)
- **Decks:** the count buttons and Remove printing on a token now sit in one column on the right edge of its picture, the same as on the card stack (#716)
- **Scanner:** the card's name and collector number are read several times faster, at the cost of about 10 MB more memory (#722)
- **Scanner:** the name and collector number are read from the full-resolution camera image, so small print is read more often and collector numbers on 2015 to 2022 cards are read more often too (#718)
- **Scanner:** once a card is locked, the scanner follows it in a small area of the frame instead of searching the whole picture, so each frame takes about half as long (#713)
- **Scanner:** a clear match is now decided after about four frames instead of ten, and the match panel shows clear beside the tally (#720)
- **Scanner:** the scanner matches a locked card with fewer image comparisons, so matching takes less time (#723)
- **Scanner:** the camera feed no longer waits while a card is looked up, so the picture keeps moving during a lookup (#717)
- **Scanner:** the rectified card preview is built only when the Developer switch is on, so the scanner does less work on every frame (#719)

### Fixed

- **Scanner:** a card laid on a card already scanned is recognised, instead of being skipped until the first card was lifted (#721)
- **Scanner:** cards that never locked in some scans, such as Graf Rats, now do, and cards in sleeves are found more reliably (#726)
- **Scanner:** a set size printed beside a collector number, such as 051/302, is no longer read as the card's number, and double-faced cards are found by either face's name, with a card's own name ranked above another card's face (#724)
- **Scanner:** when two reprints look the same, the scanner names the same printing every time instead of switching between runs (#725)
