### Highlights

- **Folder rules can now be grouped with AND and OR.** A folder can now ask for one set of conditions or another, such as a rare card or a full-art land. Older versions of the app skip these groups, so update every device that uses the same folders.
- **The scanner finds more cards in binder pockets.** Card names are now read from the top of the card even when it sits inside a binder pocket, and the regular printing is listed ahead of its promo twin. A card the scanner has picked is also no longer dropped a moment later.

### New

- **Collection:** folder rules can be combined with AND and OR groups, so a folder can ask for a price over ten dollars and a land, or for a rare card or a full-art land (#1065)
- **Collection:** pressing the red count on a folder's rules badge opens that folder showing only the cards that break its rules, and a breaks folder rules filter can be cleared from the filter bar (#1067)
- **Collection:** adding a folder keeps the name box open so several sibling folders can be typed one after another until escape or a click elsewhere ends the run (#1066)
- **Wishlist:** hovering an owned chip on a wishlist card lists the folders holding those copies and how many copies each folder holds (#1062)

### Changed

- **Wishlist:** the own and other counts now only include copies that are free to use, and copies sitting in a deck or a locked folder show as a dimmer in use chip that lists where they are and opens the collection on them (#1061)
- **Collection:** the add folder button lights up the folder row it will sit under while hovered or focused, and the top-level folder button is now labelled add top-level folder (#1066)
- **Scanner:** the scanner can read a card's name from anywhere across the top of the card, so it still recognises cards that sit inside a binder pocket (#1060)
- **Scanner:** when a card has a promo version and a regular printing that look nearly the same, the regular printing is now listed first with the promo straight after it (#1068)

### Fixed

- **Scanner:** a card the scanner has picked from its name is no longer dropped shortly afterwards when the picture keeps matching a different card (#1069)
- **Sharing:** a shared list no longer counts a foil copy as owned when you only hold nonfoil or etched copies of that printing, so the count matches the finish (#1063)
