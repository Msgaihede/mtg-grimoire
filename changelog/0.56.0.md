### Fixed

- **Sync:** a removed device can no longer push changes into its old sync group after the group's keys have been changed (#1209)
- **Sync:** a change to a sync group's keys that fails partway no longer leaves the group in a half-changed state (#1208)
- **Sync:** a device can no longer send changes or confirm progress on behalf of another device in the same group (#1207)
- **Sharing:** a device removed from a group loses access to shared content straight away when the group's keys change, even if it held a token from before (#1206)
