### Highlights

- **The home page is now a grid you can arrange.** Drag cards anywhere, resize them, and add new kinds such as Recently viewed, Set completion and Price movers from the catalogue.
- **The app opens quickly and shows its icon on the taskbar.** The window answers from the first moment, and a loading screen covers the wait while your data opens.

### New

- **General:** in Customize, you can drag a home card anywhere, pull its corner to resize it, and move or resize it with the arrow keys (#466)
- **General:** each home card has its own settings, with size controls, options for its kind, density and a title you can rename (#466)
- **General:** a widget catalogue shows a live preview of each kind of home card before you add it (#466)
- **General:** a Recently viewed home card lists the cards opened on this device (#466)
- **Collection:** a Set completion home card shows how much of each set's printed size you own (#466)
- **Prices:** a Price movers home card shows which cards gained or lost the most over 7 days, 30 days or all time (#466)
- **Prices:** the app records price history on each device, kept in detail for 35 days and thinned after that, and this history does not sync between devices (#466)

### Changed

- **General:** the home page is now a grid of resizable squares instead of a single row, and it fits itself to the window width (#466)
- **General:** removing a card from the home page now asks you to confirm first (#466)
- **General:** the card database is checked for damage after the app opens rather than before, and a damaged copy is replaced on the next start (#468)

### Fixed

- **General:** the window now opens and responds straight away, so the app's own icon appears on the taskbar instead of a generic one (#468)
- **General:** a loading screen with a message shows while the databases open, so the app no longer looks frozen on a slow start (#468)
- **General:** a database that cannot be opened now shows an error message instead of closing the app (#468)
