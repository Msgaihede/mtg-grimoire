5 notes
  • Mana base
    Nine sources of double red is one short — every hand that keeps two lands and Krenko needs the second before turn four. Cut the third utility land for a basic Mountain.
  • Sac outlets to find
    The goblin tokens need somewhere to go that is not combat. Skirk Prospector is the only one in the list so far — Ashnod's Altar and Goblin Bombardment are both in the binder.
  • Krenko line
    Haste enabler first, then the tap. Without one the whole turn is a draw step. Tested twice against the Simic deck — both times it was the haste that was missing.
  • Budget swaps if the Cavern goes
    Unclaimed Territory does the same job for a dollar as long as everything stays a Goblin — which it does, apart from Purphoros. Secluded Courtyard is the same card with a worse name on it.
  • Table notes — Thursday pod
    Two of them are on bracket 3, so the extra-turns package stays out. Nobody minded the tokens; the Bombardment finish is the part that reads as combo, so lead with the board instead.
